# Plantilla para reuniones virtuales

Esta carpeta contiene únicamente una plantilla visual reutilizable para registrar futuras reuniones del equipo.

- `plantilla_reunion_teams.png`: vista lista para insertar en documentación.
- `plantilla_reunion_teams.svg`: versión editable mediante formas y texto.

**Plantilla visual para el registro de futuras reuniones. No constituye evidencia de una reunión realizada.**

No se incluyen fecha, hora, duración ni acuerdos inventados. Cuando exista una reunión real, esos datos deberán tomarse de notas o evidencias auténticas.
